Code changes in this follow-up
internal/collector/streamjson.go records depth/selected-value failures and ignored
oversized keys using fixed reasons. responsebody.go observes one terminal result
per eligible response and one oversized-field-name notice per response. proxy.go
and usage.go distinguish malformed/invalid data from absent usage and known zero.
internal/metrics/registry.go registers two counters with bounded labels:
  ollama_proxy_extraction_total{outcome,reason}
  ollama_proxy_extraction_field_skips_total{reason}
No response content, model, arbitrary path, or arbitrary field name is placed in
these diagnostic labels or logged. Exclusions/unrelated methods/routes do not
produce extraction results. Non-2xx inference responses report skipped/http_status.
Invalid reported usage now rejects inference observations instead of becoming
missing usage. Completed responses genuinely lacking usage still count as
completed inferences and report skipped/usage_absent, without a token observation.

internal/collector/extraction_test.go checks depths 63/64/65 (root included),
selected tokens of 4095/4096/4097 encoded bytes, and field names of 127/128/129
encoded bytes, for native JSON and SSE through real HTTP servers. String fixtures
include escaped code points, so bytes cannot be confused with decoded characters.
Both quotes are included in the encoded limit. Client bytes remain identical.
Beyond the key limit, useful metrics remain and field_name_limit is observed once,
even for repeated oversized keys across SSE events. Selected-value/depth failures
produce no completion metrics. Explicit zero, absent/null usage, invalid counts,
malformed/truncated JSON, early Close, repeated EOF/Close, upstream errors, HTTP
status filtering, method/path routing, and exclusion diagnostics are tested.

The full suite also retains native and compatibility HTTP fixture coverage from
the initial implementation: prompt delivery, response fidelity, labels/trailers,
large objects, concurrent streams, aborts, cancellation, and body closure. The
first-token tests on all five supported routes read a flushed event while upstream
completion is blocked on a channel. These are mock HTTP tests, not live inference.
The 100-token/4-second and 16-token/0.125-second native fixtures remain 25 and
128 tokens/sec respectively. Native phase timing is never replaced by wall time.

G118 and vulnerability evidence

caller/helper code, cancellation ownership test and narrow suppression. The
configured linter now passes; its rule remains enabled. The security assessment
