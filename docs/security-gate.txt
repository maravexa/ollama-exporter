Final security/lint gate, 2026-10-16

Result and scope
The declared minimum Go version and Docker builder are now Go 1.26.9 (previously
1.25.9 and 1.22-alpine respectively). This fixes the 33 standard-library findings
in the earlier captured scan. Some implicated actual HTTP/TLS/proxy paths: they
were not dismissed as unreachable. No module dependency versions, runtime feature
behavior, CI vulnerability checks, services, or model installations were changed
in this security follow-up. Existing streaming work remains in the source patch.
Official release metadata and Docker builder tag metadata are retained. There is
no Docker/Podman engine on this workstation: the image itself was not built.

G118 diagnostic and cancellation ownership
The full original diagnostic is copied to G118-before.log; G118-source.txt includes
numbered surrounding helper/caller source. Original diagnostic:
  internal/remotewrite/sender.go:256:29: G118: context cancellation function returned by WithCancel/WithTimeout/WithDeadline is not called (gosec)
          return context.WithTimeout(parent, s.cfg.Timeout)
                                    ^
  1 issues:
  * gosec: 1
  exit status 1

sendContext deliberately returns context and CancelFunc to processBatch. That
caller calls cancel immediately after sendWriteRequest, before every success,
error and retry branch. No early return occurs between acquiring and cancelling
in ordinary completion paths. The timeout-disabled branch returns parent/no-op.
A single existing return expression has a scoped nolint:gosec annotation naming
G118 and ownership; the rule is otherwise enabled. TestSenderAttemptContextCancelled
verifies success/400/503 transports receive context cancellation before the long
configured deadline. This is a documented interprocedural false positive, not a
claim that a timeout substitutes for cancellation. The full suite, race tests and
configured lint all passed with the annotation and regression test.

Live verification of the rebuilt binary
validation/security-gate/live/direct-report.json records five direct-upstream
streams using the Go 1.26.9 binary, existing server 0.40.3 and installed gemma3:4b.
Native generate/chat, OpenAI chat/completions (include_usage=true), and Anthropic
messages all returned 200, content before completion, duration/completion exactly
once and in-flight zero. First native generate content took 4.243s, completion
5.399s; subsequent routes first content took 96-99ms, completion 1.234-1.237s.
This is direct HTTP smoke evidence, not a deterministic latency bound or a UI test.
server-and-cleanup.json records actual /api/version, installed model metadata and
closure of both temporary localhost listeners. No response contents were retained.
The earlier 14-case byte-fidelity/usage presence/absence matrix remains under
validation/live-ollama and docs/live-validation.txt; it used the separate Go 1.25.9
binary. This follow-up did not repeat that entire matrix or the parser benchmark.
Live thinking-model behavior and Open WebUI rendering are explicitly untested;
this release does not claim live UI support. Parser bounds/allocations and framing
are covered by the earlier retained tests/benchmark; the unchanged tests also pass
under the new compiler. No assertion is made that all regressions are prevented.
